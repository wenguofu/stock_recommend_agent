# 十倍股筛选条件清单

> 基于 存储芯片(10x) + 源杰科技(14x) 两个已验证案例的共性提炼
> 
> 核心公式: **供需缺口(60%) + 稀缺性(20%) + 代际跃迁(10%) + 估值底部(10%) = S级主线**

---

## 一、五个硬条件（必须全部满足）

### 🔴 条件1：供需剪刀差 — 权重60%

| 子指标 | 阈值 | 验证方法 |
|------|:---:|------|
| 行业产能利用率 | **>90%** | 行业协会报告/公司财报 |
| 需求增速 | **>50%/年** | 下游客户CAPEX指引 |
| 产品价格趋势 | **连续2个季度上涨** | 现货/合约价格指数 |
| 供给扩张周期 | **>18个月才能新增产能** | 晶圆厂/产线建设周期 |

> 源杰案例：光芯片产能仅满足需求30%，新产能需2年。  
> 存储案例：HBM挤占DRAM产能，12寸晶圆供不应求。

**如何发现**：关注"涨价""供不应求""产能不足""交期延长"关键词出现频率陡增的行业。

---

### 🔴 条件2：稀缺性/唯一性 — 权重20%

| 类型 | 检查 | 范例 |
|------|------|------|
| **国产唯一** | 国内是否只有1-2家企业能做？ | 源杰：唯一25G EML量产 |
| **全球寡头** | 全球是否只有3-5家供应商？ | 存储：三星/海力士/美光三巨头 |
| **技术壁垒** | 新进入者需要几年才能追赶？ | 光芯片：5-10年技术积累 |
| **专利/认证壁垒** | 是否存在不可逾越的护城河？ | 车规认证、军工资质 |

**如何发现**：在细分领域搜索"国内首家""唯一量产""打破垄断""进口替代"等标签。

---

### 🟡 条件3：技术代际跃迁 — 权重10%

| 阶段 | 特征 | 估值影响 |
|------|------|:---:|
| N代量产 | 基础产品 | PE 50-80x |
| N+1代送样 | 追赶国际主流 | PE 100-150x |
| N+1代量产 | 国产替代落地 | PE 150-250x |
| N+2代流片 | 进入全球第一梯队 | PE 250-400x |

> 源杰案例：10G(80x)→25G量产(150x)→50G送样(250x)→100G流片(400x)  
> 存储案例：DDR4(25x)→DDR5(50x)→HBM(100x+)

**如何发现**：跟踪公司产品路线图，关注"流片成功""送样验证""客户导入""小批量产"等公告。

---

### 🟡 条件4：估值在周期底部 — 权重5%

| 子指标 | 阈值 |
|------|:---:|
| 股价从高点回撤 | **>60%** |
| PE/PB历史分位 | **<20%**（10年分位） |
| 横盘时间 | **>3个月** |
| 机构持仓 | **低于行业均值** |
| 成交量 | **萎缩到峰值20%以下** |

> 源杰案例：从IPO价¥200跌到¥88（-56%），横盘3个月。  
> 存储案例：2023年DRAM价跌50%+，全行业亏损，PE压缩到25x。

**如何发现**：用 `db_scanner.py` 扫全市场PE<20分位+横盘>60天的票。

---

### 🟢 条件5：催化剂节奏 — 权重5%

未来**6个月内**必须有至少2-3个明确里程碑：

| 催化剂类型 | 示例 |
|------|------|
| 新产品流片/量产 | "50G EML预计Q3流片" |
| 大客户导入 | "已进入NV供应链验证" |
| 产能扩张 | "二期产线Q4投产，产能翻倍" |
| 政策落地 | "大基金三期注资" |
| 行业标准变更 | "CPO标准正式发布" |

## 二、否决条件（一票否则）

| 条件 | 说明 |
|------|------|
| ❌ 纯概念无产品 | 只有PPT没有量产能力的公司 |
| ❌ 已涨3倍以上 | 从底部涨3倍后追入不是十倍股逻辑 |
| ❌ 市场空间<500亿 | TAM太小，容不下大资金 |
| ❌ 技术路线被替代风险 | 如硅光 vs 磷化铟 路线之争 |
| ❌ 管理层不靠谱 | 有减持/质押/关联交易污点 |

---

## 三、筛选流程

```
Step 1: 产业研究 → 找出供不应求的细分行业
         ↓
Step 2: 稀缺性过滤 → 只留国产唯一的1-2家公司
         ↓
Step 3: 技术验证 → 确认有N→N+1代际升级路线图
         ↓
Step 4: 估值择时 → 等PE历史低分位+横盘3个月
         ↓
Step 5: 催化剂匹配 → 确保未来6个月有里程碑
         ↓
        🔴 S级信号 → 重仓
```
