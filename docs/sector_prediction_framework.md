## 二、归因分析：存储芯片10倍的7层驱动

### 🔴 Layer 1：供需剪刀差（最核心，占60%权重）

```
2023: 史上最惨烈下行周期
  ├─ DRAM现货价跌50%+
  ├─ 三星/海力士/美光集体减产
  └─ 全产业链极致去库存

2024H2: 供需逆转
  ├─ AI HBM需求爆炸 → 3x晶圆消耗 vs 普通DRAM
  ├─ 三大原厂产能转向HBM → 挤占普通DRAM/NAND产能
  ├─ DDR4→DDR5换代加速 → ASP提升30-50%
  └─ 下游补库周期启动 → 量价齐升
```

**核心指标**：当存储原厂库存周转天数从>120天降到<60天，就是反转信号。

### 🔴 Layer 2：AI算力拉动（占20%权重）

- **HBM**：NVIDIA H200/B200/GB200标配HBM3e，单GPU配6-8颗，每颗$2000+
- **边缘AI**：AI PC/Phone标配24-32GB内存，是传统设备的2-3倍
- **推理需求**：大模型推理需要大量KV Cache，直接拉动DRAM需求
- **存储墙问题**：算力每2年翻倍，存储带宽增速仅1.5倍 → 差距持续拉大 → 存储必涨

### 🟡 Layer 3：国产替代+地缘催化（占10%权重）

- 美国对华芯片制裁持续加码 → HBM对华禁运
- **长鑫存储(CXMT)** DDR5量产突破 → 国产DRAM从0到1
- **长江存储(YMTC)** 232层NAND → 全球领先
- 国内模组厂（佰维、江波龙）受益于国产颗粒供应

### 🟡 Layer 4：产业周期共振（占5%权重）

- 存储是半导体最强周期品 → 弹性最大
- 上行周期通常持续6-8个季度
- 2025年全球存储市场规模预计$2000亿+，同比+80%

### 🟢 Layer 5：资金行为（占3%权重）

- 2024年底存储板块机构持仓极低（底部特征）
- 2025H1开始机构大规模建仓 → 形成正向反馈
- 板块成交额从日均50亿飙升至300亿+ → 流动性溢价

### 🟢 Layer 6：政策支持（占1%权重）

- 大基金三期重点投向存储
- 各地方补贴存储产线建设
- 信创招标强制国产存储

### 🟢 Layer 7：情绪放大器（占1%权重）

- "存储涨价"成为市场共识 → 散户涌入
- 媒体报道/NV链效应 → 正反馈循环
- 板块效应：龙头涨→二三线跟涨→全面扩散

## 三、主线预判框架（SECTOR_PREDICTION）

### 核心原理

**任何10倍主线 = 供需剪刀差(60%) + 技术/产品周期(20%) + 政策催化(10%) + 资金/情绪(10%)**

### 六因子评分模型

| 因子 | 权重 | 评分标准 | 数据源 |
|------|:---:|------|------|
| **供需失衡度** | 30% | 供给约束×需求弹性：0-10分 | 行业库存/产能利用率/价格指数 |
| **产业周期位置** | 20% | 底部反转>加速期>顶部：0-10分 | 历史价格/估值分位 |
| **技术突破量级** | 15% | 0→1(10分) > 1→N(5分) > 延续(2分) | 专利/量产公告/标准变更 |
| **政策催化强度** | 15% | 国家级(10分) > 部委级(6分) > 地方(2分) | 国务院/发改委/工信部文件 |
| **资金流入信号** | 10% | 机构建仓+成交量放大：0-10分 | 龙虎榜/北向/融资余额 |
| **板块估值弹性** | 10% | 历史低分位(10分) > 中分位(5分) > 高(1分) | PE/PB历史分位 |

### 4道验证关卡

```
Gate 1: 供需验证 — 是否有真实供需缺口？（过滤纯概念炒作）
  ├─ 必过项：产品价格趋势↑ + 库存天数↓
  └─ 否决项：只是"预期"没有实际数据支撑

Gate 2: 周期验证 — 是否在周期底部？（过滤追高）
  ├─ 必过项：估值分位<30% + 机构持仓<均值
  └─ 否决项：已经涨了3倍以上再谈"主线"

Gate 3: 机构验证 — 聪明钱是否在进场？（过滤散户自嗨）
  ├─ 必过项：北向/机构连续2周净流入 OR 卖方覆盖密度增加
  └─ 否决项：只有游资/散户在买

Gate 4: 龙头验证 — 板块龙头是否领涨？（过滤假启动）
  ├─ 必过项：板块TOP3市值标的表现>板块均值
  └─ 否决项：涨的都是边缘小票
```

### 预判输出的信号等级

| 等级 | 条件 | 含义 |
|:---:|------|------|
| 🔴 S级 | 总分≥80 + 4门全过 | **高确定性主线**，可重仓 |
| 🟠 A级 | 总分≥65 + 过3门 | 强候选，中等仓位 |
| 🟡 B级 | 总分≥50 + 过2门 | 关注级，轻仓试探 |
| ⚪ C级 | 总分<50 | 不满足条件，观望 |
