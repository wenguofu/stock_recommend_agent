## 3. Layer 1：技术面宽筛

**目标**: 从5520只股票筛选出100-200只候选

### 3.1 大盘环境过滤器（先决条件）

**必须满足以下条件才进行筛选**，否则暂停推荐：

| 条件 | 阈值 | 说明 |
|------|------|------|
| 涨幅>8%股数 | < 50 | 市场做多意愿过弱时不筛选 |
| 跌幅>8%股数 | > 50 | 恐慌抛售蔓延时不筛选 |

**数据来源**: `market_monitor.py` 的 `check_market_breadth()` 函数，使用 akshare：
- `stock_zt_pool_strong_em()` → 涨幅>8%股票池
- `stock_zt_pool_dtgc_em()` → 跌停股票池

```python
def is_market_safe_for_screening() -> Tuple[bool, dict]:
    """检查大盘环境是否适合筛选"""
    strong = ak.stock_zt_pool_strong_em()  # 涨幅>8%
    limit_down = ak.stock_zt_pool_dtgc_em()  # 跌停
    
    strong_count = len(strong[strong['涨跌幅'] > 8])
    limit_down_count = len(limit_down)
    
    is_safe = (strong_count >= 50) and (limit_down_count <= 50)
    return is_safe, {
        'strong_count': strong_count,
        'limit_down_count': limit_down_count,
        'reason': 'safe' if is_safe else 'market_risk'
    }
```

### 3.3 个股基础条件

#### 短线条件（5-20天持仓）

| 条件 | 阈值 | 说明 |
|------|------|------|
| 股票类型 | 非ST、非退市 | 排除风险股 |
| 流动性 | 日均成交 > 5000万 | 排除僵尸股 |
| 上市时间 | > 120天 | 排除新股 |
| 所属板块 | 在热门板块列表中 | 只做主线 |

#### 中线条件（1-3个月持仓）

| 条件 | 阈值 | 说明 |
|------|------|------|

## 4. Layer 2：多信号评分

**目标**: 对Layer 1候选股进行多信号加权评分，取Top 20-30

### 4.1 短线评分体系（权重100%）

| 信号类型 | 具体指标 | 权重 | 评分规则 |
|---------|---------|------|----------|
| **量价突破** | 收盘突破20日高点 | 20% | 突破5%+得满分，3-5%得80% |
| | 成交量 > 1.5x 20日均量 | 15% | 3x+满分，1.5-3x按比例 |
| | 价格站上MA5/10/20 | 10% | 3条均线得满分 |
| **趋势确认** | MA5 > MA20 (均线多头) | 15% | 金叉得满分 |
| | RSI 40-70 | 10% | 50-60满分，超买扣分 |
| | 近10日最大回撤 < 10% | 10% | 5%以内满分 |
| **资金信号** | 5日资金净流入 > 0 | 15% | 正流入得分 |
| | 量比持续放大 | 5% | 3日量比上升得分 |

### 4.2 中线评分体系（权重100%）

| 信号类型 | 具体指标 | 权重 | 评分规则 |
|---------|---------|------|----------|
| **趋势确认** | MA10 > MA60 (金叉) | 20% | 金叉得满分 |
| | 60日涨幅 20%-80% | 15% | 40-60%满分 |
| **突破信号** | 突破60日高点 | 15% | 突破10%+满分 |
| | 成交量 > 2x 60日均量 | 10% | 3x+满分 |
| **基本面** | ROE > 10% | 15% | 15%+满分 |
| | 毛利率 > 25% | 10% | 30%+满分 |
| | 利润增速 > 20% | 15% | 30%+满分 |

```
3. 统计出现相同信号后，5/10/20日后的上涨概率

```

## 6. Layer 4：模拟盘监控

### 6.1 每日流程

| 时间 | 操作 |
|------|------|
| 开盘前 | 展示当日推荐股票及理由 |
| 盘中 | 监控持仓股票价格/信号变化 |
| 收盘后 | 更新信号状态，评估是否调仓 |

### 6.2 监控指标

| 指标 | 阈值 | 动作 |
|------|------|------|
| 价格止损 | 亏损 > 7% | 触发止损警告 |
| 目标达成 | 盈利 > 15% | 建议部分止盈 |
| 信号恶化 | RSI > 75 或 死叉 | 预警 |
| 新推荐 | - | 推送通知 |

### 6.3 调仓规则

| 情况 | 操作 |
|------|------|
| 止损触发 | 100%卖出 |
| 目标达成 | 50%止盈，保留50% |
| 更好的推荐出现 | 评估是否换仓 |
| 信号持续恶化 | 逐步减仓 |
